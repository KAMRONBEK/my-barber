# 🚀 Complete Deployment Guide

## ✅ **Project Structure**

The deployment uses a simplified root-level TypeScript structure:

```
├── server.ts             # Main server file (compiles to server.js)
├── config/               # Configuration files
├── middleware/           # Express middleware
├── routes/               # API routes
├── services/             # Business logic services
├── models/               # Data models
├── utils/                # Utility functions
├── dist/                 # Compiled JavaScript (generated by tsc)
├── vercel.json           # Vercel deployment configuration
└── package.json          # Dependencies and scripts
```

## 🎯 **Quick Deployment Steps**

### **Step 1: Install & Login to Vercel**
```bash
npm install -g vercel
vercel login
```

### **Step 2: Environment Variables**

#### **Production Environment:**
```bash
vercel env add NODE_ENV production
vercel env add FIREBASE_PROJECT_ID my-barber-production
vercel env add FIREBASE_PRIVATE_KEY "-----BEGIN PRIVATE KEY-----\nYour-Production-Private-Key\n-----END PRIVATE KEY-----\n" production
vercel env add FIREBASE_CLIENT_EMAIL firebase-adminsdk-xxxxx@my-barber-production.iam.gserviceaccount.com production
vercel env add FIREBASE_STORAGE_BUCKET my-barber-production.appspot.com production
vercel env add JWT_SECRET your-production-jwt-secret-here production
vercel env add EXPO_ACCESS_TOKEN your-expo-production-token production
vercel env add CORS_ORIGIN https://app.my-barber.uz production
```

#### **Staging Environment:**
```bash
vercel env add NODE_ENV staging
vercel env add FIREBASE_PROJECT_ID my-barber-staging
vercel env add FIREBASE_PRIVATE_KEY "-----BEGIN PRIVATE KEY-----\nYour-Staging-Private-Key\n-----END PRIVATE KEY-----\n" staging
vercel env add FIREBASE_CLIENT_EMAIL firebase-adminsdk-xxxxx@my-barber-staging.iam.gserviceaccount.com staging
vercel env add FIREBASE_STORAGE_BUCKET my-barber-staging.appspot.com staging
vercel env add JWT_SECRET your-staging-jwt-secret-here staging
vercel env add EXPO_ACCESS_TOKEN your-expo-staging-token staging
vercel env add CORS_ORIGIN https://staging-app.my-barber.uz staging
```

### **Step 3: DNS Configuration (ahost.uz)**

Add these CNAME records in your ahost.uz control panel:

```
# Production API
Type: CNAME
Name: api
Value: cname.vercel-dns.com
TTL: 3600

# Staging API
Type: CNAME
Name: staging-api
Value: cname.vercel-dns.com
TTL: 3600
```

### **Step 4: Deploy**

#### **Deploy Production:**
```bash
npm run vercel:production
vercel alias api.my-barber.uz
```

#### **Deploy Staging:**
```bash
npm run vercel:staging
vercel alias staging-api.my-barber.uz
```

## 🔧 **Domain Setup Troubleshooting**

### **Add Domain via Vercel Dashboard**
1. Go to [Vercel Dashboard](https://vercel.com/dashboard)
2. Select your `my-barber-api` project
3. Go to **Settings > Domains**
4. Click **Add Domain** and enter: `api.my-barber.uz`

### **Common Issues & Solutions**

#### **"Domain already in use"**
Add a TXT record for verification:
```
Name: _vercel
Value: [verification-code-from-vercel]
```

#### **SSL Certificate Error**
Add CAA record if needed:
```
Type: CAA
Name: @
Value: 0 issue "letsencrypt.org"
```

### **DNS Verification**
```bash
# Check CNAME record
dig CNAME api.my-barber.uz

# Expected result: cname.vercel-dns.com
```

## 🚨 **Emergency Troubleshooting**

### **If deployment fails:**
```bash
# Remove and re-add domain
vercel domains rm api.my-barber.uz
vercel domains add api.my-barber.uz

# Clear DNS cache
ipconfig /flushdns  # Windows
sudo dscacheutil -flushcache  # macOS/Linux

# Redeploy
vercel --prod
```

### **Common Environment Variable Issues**
- Check FIREBASE_PRIVATE_KEY formatting (include \n characters)
- Ensure all required variables are set
- Verify Firebase project IDs are correct
- Set CORS_ORIGIN to your frontend domain or "*" for testing

**Need help?** Check the logs with `vercel logs --follow` and share any specific error messages!
